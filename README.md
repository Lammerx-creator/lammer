# DeutschTrainer

Персональное приложение для русскоязычного пользователя, изучающего немецкий на уровнях B1–C1. Главный учебный сценарий MVP — **Passiv в контексте B2 Beruf**. Приложение создано в изначально пустом репозитории `Lammerx-creator/lammer`.

React 19, TypeScript, Vite 6, Tailwind CSS 4, IndexedDB и PWA. Сервер, регистрация, платные API и ключи доступа не нужны.

Приложение опубликовано на GitHub Pages: **https://lammerx-creator.github.io/lammer/**. Исходники находятся в `main`, статическая сборка — в `gh-pages`; Pages использует корень этой ветки и HTTPS. Публикация выполнена по явному запросу пользователя.

## Запуск

Нужен Node.js 22+; разработка проверялась на Node.js 24.19.0 и npm 11.9.0.

```sh
cd /workspace/lammer
npm ci
npm run dev
```

Vite выводит адрес и порт в терминале. На другом компьютере используйте фактический путь к клону. Рабочая копия уже находится в изолированной среде задачи: дополнительный Git worktree для запуска не нужен.

```sh
npm test             # проверка ответов, SM-2, статистики и хранения
npm run typecheck    # TypeScript
npm run build        # TypeScript и production-сборка в dist/
npm run preview      # локальная проверка production-сборки, включая PWA
```

`npm run dev` предназначен для разработки и намеренно не регистрирует service worker. Проверяйте офлайн-режим через production-сборку. `preview` — средство локальной проверки, а не команда публикации.

## Что реализовано

- Passiv: 50 авторских упражнений с эталонными ответами, русскими подсказками и объяснениями. Пять групп: Vorgangspassiv, Zustandspassiv, Passiv с модальными глаголами, времена и профессиональные ситуации. Времена включают Präsens, Präteritum, Perfekt, Plusquamperfekt, Futur I и Futur II; есть примеры с придаточными предложениями и Konjunktiv II.
- Выбор ответа, полное заполненное предложение, сборка из слов, перевод, исправление ошибки, преобразование Aktiv → Passiv и понимание аудио. Уровни B1, B2 и C1 позволяют увеличивать сложность.
- Словарь с профессиональной лексикой, собственными карточками и интервальным повторением SM-2. Оценка после раскрытия перевода — самооценка вспоминания слова.
- Аудирование рабочих текстов с вопросами и объяснениями.
- Темы разговорной практики, текстовый ответ и, при поддержке браузера, распознавание и запись речи. Автоматической оценки свободной речи нет: результат проверяется самостоятельно по заданным пунктам.
- Локальный прогресс, правильность ответов, активные дни, серия занятий, ошибки и результаты по темам.
- Экспорт и импорт JSON, адаптивный интерфейс и PWA.

Это MVP с полноценным Passiv. Исчерпывающие отдельные курсы по всем остальным грамматическим темам B2 пока не реализованы. Следующий этап — самостоятельные наборы упражнений по Konjunktiv II, Relativsätze, управлению глаголов, Präpositionen и N-Deklination, затем расширение диалогов и профессиональных сценариев. Встречающийся в Passiv пример с другой конструкцией не заменяет отдельный курс по этой теме.

## Проверка ответов

Ответ сравнивается с явным списком допустимых эталонов. Учитываются регистр, Unicode, пробелы и конечная пунктуация; смысловые ошибки и произвольный порядок слов не принимаются автоматически. Альтернативные правильные конструкции добавляются в `answers` конкретного задания. Умлауты не удаляются, `ss` и `ß` не смешиваются безусловно.

В заданиях с пропуском вводится **целое завершённое предложение**, если это указано в инструкции. В свободной разговорной практике приложение честно использует самооценку. Оно не имитирует понимание произвольного немецкого текста.

## Данные и резервные копии

Результаты, пользовательские слова, расписание повторений и настройки хранятся в IndexedDB текущего браузера. Встроенный словарь находится в исходном коде. Между устройствами данные автоматически не синхронизируются; приватный режим и очистка данных сайта могут удалить прогресс.

Регулярно экспортируйте JSON, особенно перед очисткой браузера, сменой устройства или импортом. Импорт проверяет версию, типы полей и ограничения размера и **заменяет локальные данные** после подтверждения. Перед заменой сохраните актуальную резервную копию. Некорректный файл не должен частично менять прогресс.

Пользовательский ввод отображается как текст средствами React; HTML не исполняется. Не храните в словаре секретные данные. Экспорт содержит введённые ответы и пользовательскую лексику, поэтому передавайте файл осознанно.

## Офлайн, iPhone и микрофон

После первого успешного открытия production-сборки онлайн и завершения установки service worker интерфейс, упражнения, встроенный словарь и локальная статистика доступны без сети. Service worker заранее сохраняет HTML, JS, CSS, manifest и иконки. При первом открытии без сети приложение ещё не установлено и загрузиться не сможет. После изменения сборки используется новый кэш; старые кэши приложения удаляются после успешного обновления.

На iPhone откройте опубликованный HTTPS-адрес приложения в Safari, затем «Поделиться» → «На экран Домой». PWA и доступ к микрофону на реальном устройстве требуют HTTPS; исключение браузера для `localhost` относится только к локальной разработке. Для проверки собственной локальной сборки на iPhone нужен доступный этому устройству HTTPS-адрес.

`SpeechSynthesis` использует немецкие голоса, доступные в системе. Список голосов может загружаться с задержкой. Наличие и качество офлайн-голосов зависит от устройства; некоторые голоса требуют сети. Браузерное распознавание речи поддерживается не везде и может обращаться к внешнему сервису браузера — офлайн-работа распознавания не гарантируется. Платные API приложение не вызывает.

Микрофон включается только после действия пользователя и разрешения браузера. При отказе или отсутствии возможностей остаются текстовый ответ и самостоятельная проверка. Запись и распознавание имеют отдельную поддержку браузерами; наличие одного не гарантирует другое. Записи не отправляются серверу приложения и не входят в JSON прогресса.

## Структура

```text
src/
  components/         интерфейс и дополнительные учебные модули
  data/               упражнения, правила и встроенный словарь
  lib/checker.ts      проверка эталонных ответов
  lib/progress.ts     статистика и SM-2
  lib/storage.ts      IndexedDB, экспорт и валидация импорта
  lib/pwa.ts          регистрация production service worker
  types.ts            контракты учебных данных
public/
  sw.js               офлайн-кэш
  manifest.webmanifest
  icons/
```

Чтобы расширить курс, добавьте структурированные упражнения с уникальными идентификаторами, проверенными эталонами и русским объяснением. Отдельно проверьте корректные альтернативы, ошибочные близкие ответы и целевые грамматические конструкции. Изменения интерфейса для добавления заданий существующих типов не нужны.

## Статический хостинг и обновление GitHub Pages

Приложение можно разместить на HTTPS-хостинге как содержимое `dist/`. По умолчанию базовый путь — `/`. Для страницы проекта GitHub Pages `https://lammerx-creator.github.io/lammer/` нужна отдельная сборка с базовым путём `/lammer/`:

```sh
npm run build -- --base=/lammer/
npm run preview -- --base=/lammer/ --port 4174
```

Параметр `--base` задаётся **во время сборки**, а не после загрузки файлов на хостинг. HTML, manifest, иконки, регистрация service worker и офлайн-кэш учитывают этот путь через `import.meta.env.BASE_URL`. Manifest использует относительные адреса; service worker работает только в пределах своей области и очищает только кэши этой установки. При смене пути сделайте новую сборку.

Для текущей публикации Pages использует ветку `gh-pages` и каталог `/ (root)`. Содержимое `dist/` публикуется туда вместе с `.nojekyll`; исходники приложения остаются в `main`. При обновлении сохраняйте историю ветки и отправляйте обычный push, без force-push. Пример отдельного checkout для новой сборки:

```sh
npm ci
npm test
npm run build -- --base=/lammer/
deutschtrainer_pages_dir="$(mktemp -d /tmp/deutschtrainer-pages.XXXXXX)"
git clone --single-branch --branch gh-pages https://github.com/Lammerx-creator/lammer.git "$deutschtrainer_pages_dir"
rsync -a --delete --exclude='.git' dist/ "$deutschtrainer_pages_dir/"
touch "$deutschtrainer_pages_dir/.nojekyll"
git -C "$deutschtrainer_pages_dir" add --all
git -C "$deutschtrainer_pages_dir" commit -m "Update DeutschTrainer static build"
git -C "$deutschtrainer_pages_dir" push origin gh-pages
```

Команды публикации требуют права записи в репозиторий. После push дождитесь завершения сборки Pages и проверьте внешний адрес; сам push ещё не подтверждает готовность сайта. Если сборка не изменилась, новый коммит не нужен. Секреты для самого приложения не нужны.

Локальный прогресс привязан к origin браузера: данные среды разработки не появятся на внешнем домене автоматически — перенесите их экспортом и импортом JSON. Сервер не синхронизирует данные между устройствами.
